Why this matters: Power BI's native APIs (Get Activity Events, scanner) only emit report-level ViewReport events. For multi-page reports — common in clinical-trial tracking where reports can have 40–80 pages — report-level views drastically underrepresent actual usage. This dashboard demonstrates the centralized page-level rollup that BI teams need, built from the per-report Usage Metrics datasets via XMLA. It's the bridge until the Monitor Usage Metrics for Workspaces preview GAs.
